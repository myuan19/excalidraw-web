# Xmind 拖拽交换算法 — 原理报告

> 源码位置：`renderer/7744.js`（3.3MB 渲染引擎），核心函数经 Webpack 压缩后变量名已混淆，本文已还原语义。

## 一、整体架构

Xmind 的拖拽系统分为三层：

```
┌──────────────────────────────────────────────┐
│  手势层 (Gesture Layer)                       │
│  pointer 事件 → 状态机 → 发射拖拽事件           │
├──────────────────────────────────────────────┤
│  决策层 (Decision Layer)                      │
│  拖拽事件 → 命中测试 → 确定放置目标/吸附         │
├──────────────────────────────────────────────┤
│  执行层 (Execution Layer)                     │
│  提交放置 → 修改数据模型 → 重新布局渲染          │
└──────────────────────────────────────────────┘
```

## 二、手势状态机

拖拽基于 pointer 事件（`pointerdown` / `pointermove` / `pointerup`），内部维护一个状态机：

```
状态列表：idle → reached → tapped / reachedAgain / dragging / browsing

事件序列：
  pointerdown → aim + reach（标记触点位置）
  pointermove（位移超过阈值 8px） → lift（抬起节点）→ 进入 dragging 状态
  pointermove（dragging 中） → drag（持续拖拽）
  pointerup（dragging 中） → drop（放置）
```

### 关键阈值

| 常量 | 值 | 含义 |
|------|---|------|
| 拖拽启动距离 | **8px** | pointer 移动超过 8px 才认为开始拖拽（而非点击） |
| 双击判定距离 | 由 `nl` 控制 | 两次点击位置在此范围内视为双击 |

### 状态机核心代码（还原后）

```javascript
// 手势处理器
function gestureHandler(event, state) {
  switch (event.type) {
    case "pointerdown":
      if (state.status === "idle") {
        emit({ kind: "aim", ...location });
        emit({ kind: "reach", ...location });
        state.status = "reached";
        state.location = location;
      }
      break;

    case "pointermove":
      if (state.status === "reached" || state.status === "reachedAgain") {
        // 移动距离超过阈值 → 启动拖拽
        if (!isWithinDistance(location, state.location, 8)) {
          sessionState.duringDragging = true;
          emit({ kind: "lift", ...state.location });
          state.status = "dragging";
        }
      }
      else if (state.status === "dragging") {
        emit({ kind: "drag", ...location, shift, alt, ctrl });
      }
      break;

    case "pointerup":
      if (state.status === "dragging") {
        sessionState.duringDragging = false;
        emit({ kind: "drop", ...location });
        state.status = "idle";
      }
      break;
  }
}
```

## 三、拖拽决策 — 放置目标解算

### 3.1 事件处理入口

每次 `drag` 事件触发时，决策层执行以下步骤：

```javascript
function handleDragEvent(event, state) {
  const location = eventToSheetCoord(event);

  // 1. 计算吸附（Snap）
  const snapTargets = computeSnapTargets(startPoint, location, sheetFigure, sourceTopics);
  const snapOffset = resolveSnapOffset(snapTargets);

  // 2. 应用吸附偏移
  const snappedLocation = add(location, snapOffset ?? ZERO);

  // 3. 判断特殊情况
  if (isCalloutTopic || isFreePositionAllowed) {
    possibleDrop = "freePosition";  // 自由定位模式
  }
  else if (isDetachMode) {
    possibleDrop = "detach";  // 脱离为浮动节点
  }
  else {
    // 4. 核心：查找放置目标
    possibleDrop = findDropTarget(snappedLocation, sheetFigure, sourceTopics);
  }

  // 5. 如果找不到任何放置目标
  if (!possibleDrop) {
    possibleDrop = canHaveFloatingTopics ? "detach" : null;
  }
}
```

### 3.2 放置目标的三种结果

| possibleDrop 值 | 含义 | 结果 |
|----------------|------|------|
| `{ parentTopicId, insertionIndex, ... }` | **作为子节点插入** — 放到某个父节点的第 N 个子节点位置 | 修改父子关系和排序 |
| `"detach"` | **脱离为浮动节点** — 拖到空白区域 | 变成独立浮动节点 |
| `"freePosition"` | **自由定位** — 在画布上自由放置 | 仅改变坐标，不改变树结构 |
| `null` | **无有效目标** — 鼠标显示禁止图标 | 放置操作无效 |

## 四、放置目标查找算法（核心）

### 4.1 `findDropTarget` — 遍历树查找命中区域

```javascript
function findDropTarget(point, sheetFigure, sourceTopics, scopeTopics) {
  // 从后向前（z-order 从上到下）遍历所有节点
  return traverseTopicTree(sheetFigure, {
    backward: true,             // 后序遍历（上层节点优先）
    scopeTopics: scopeTopics,   // 限定搜索范围
    prune: (topicFigure) => {
      // 剪枝优化：如果鼠标不在该分支的 droppable 区域内，跳过整棵子树
      return !pointInRect(point, offsetRect(
        topicFigure.overallDroppableRegion ?? topicFigure.branch.bounds,
        topicFigure.anchorPoint
      ));
    }
  }, (topicFigure) => {
    // 对每个节点，检查其放置目标列表
    return testDropTargetsForTopic(point, topicFigure, sourceTopics, sheetFigure);
  });
}
```

### 4.2 `testDropTargetsForTopic` — 测试单个节点的放置区域

```javascript
function testDropTargetsForTopic(point, topicFigure, sourceTopics, sheetFigure) {
  // 如果节点在视口外或不能有子节点，跳过
  if (topicFigure.isOutOfScope) return null;
  if (!topicFigure.canHaveChildrenTopics) return null;

  // 遍历该节点的所有 dropTarget（放置区域）
  for (const target of topicFigure.dropTargets) {
    // 1. 命中测试：鼠标是否在该放置区域内
    if (!pointInRect(point, offsetRect(target.region, topicFigure.anchorPoint))) {
      continue;
    }

    // 2. 合法性检查：拖拽的节点能否放到这个位置
    const isValid = sourceTopics.every(topic => {
      const topicFigure = sheetFigure.topicFigureByTopicId[topic.id];
      if (!topicFigure) return false;
      // 不能把节点放到自己的子树中
      return topicFigure.isDropAvailableFor(target.drop)
        && topic.asMovable({ parent: { id: target.drop.parentTopicId }, at: target.drop.insertionIndex });
    });

    if (isValid) {
      return target.drop;  // 返回: { parentTopicId, insertionIndex }
    }
  }

  return null;
}
```

### 4.3 `pointInRect` — 点在矩形内判定

```javascript
function pointInRect(point, rect, epsilon = 1e-7) {
  return isBetween(point.x, rect.x, rect.x + rect.width, epsilon)
      && isBetween(point.y, rect.y, rect.y + rect.height, epsilon);
}
```

## 五、放置区域的计算（dropTargets）

每个节点会预计算一组**放置区域**（dropTargets），这些区域定义了"拖拽节点放到哪里会被插入为第几个子节点"。

### 5.1 树状结构的放置区域

对于标准的树状布局（如逻辑图、组织结构图），放置区域的计算如下：

```javascript
function computeTreeDropTargets(topicFigure) {
  const { topicId, node, branch } = topicFigure;
  const children = topicFigure.visibleChildrenTopics;
  const nodeRect = node.nodeView;       // 父节点自身的矩形
  const majorSpacing = branch.majorSpacing;  // 子节点间距
  const growthDirection = topicFigure.primaryGrowthDirection;  // 生长方向

  // === 无子节点时 ===
  if (children.length === 0) {
    // 创建唯一一个放置区域：insertionIndex = 0
    return [{
      drop: { parentTopicId: topicId, insertionIndex: 0 },
      region: computeEmptyChildRegion(nodeRect, majorSpacing, growthDirection)
    }];
  }

  // === 有子节点时 ===
  // 为每个相邻子节点之间创建一个放置区域
  const targets = [];

  for (let i = 0; i <= children.length; i++) {
    const prevChild = i > 0 ? children[i - 1] : null;
    const nextChild = i < children.length ? children[i] : null;

    const region = computeInsertionRegion(
      prevChild,    // 前一个子节点（可为 null）
      nextChild,    // 后一个子节点（可为 null）
      nodeRect,
      growthDirection
    );

    targets.push({
      drop: { parentTopicId: topicId, insertionIndex: i },
      region: region
    });
  }

  return targets;
}
```

### 5.2 插入区域的几何计算

每个插入区域是一个**凸包矩形**，由前后两个子节点的边界框决定：

```
假设树向右生长 (growthDirection = "right")，子节点从上到下排列：

父节点
  ├── 子节点0  ─┐
  │             │ ← 放置区域0 (insertionIndex=0): 子节点0 上方
  ├── 子节点1  ─┤
  │             │ ← 放置区域1 (insertionIndex=1): 子节点0 和 1 之间
  ├── 子节点2  ─┤
  │             │ ← 放置区域2 (insertionIndex=2): 子节点1 和 2 之间
  └─            ┘ ← 放置区域3 (insertionIndex=3): 子节点2 下方
```

区域的精确计算：

```javascript
function computeInsertionRegion(prevChild, nextChild, parentNode, direction) {
  if (prevChild && nextChild) {
    // 在两个子节点之间：区域 = 合并(前一个分支底部 → 后一个分支顶部)
    return boundingRect(
      { x: left(prevChild.branchBounds), y: prevChild.offset.y },
      { x: right(prevChild.nodeBounds),  y: prevChild.offset.y },
      { x: left(nextChild.branchBounds), y: nextChild.offset.y },
      { x: right(nextChild.nodeBounds),  y: nextChild.offset.y }
    );
  }
  else if (nextChild && !prevChild) {
    // 第一个位置（最前面）：区域 = 从第一个子节点上方扩展
    return boundingRect(
      { x: left(nextChild.branchBounds), y: top(nextChild.branchBounds) - REGION_EXPANSION_START },
      { x: left(nextChild.branchBounds), y: nextChild.offset.y },
      { x: right(nextChild.nodeBounds),  y: nextChild.offset.y }
    );
  }
  else if (prevChild && !nextChild) {
    // 最后一个位置（最后面）：区域 = 从最后一个子节点下方扩展
    return boundingRect(
      { x: left(prevChild.branchBounds), y: prevChild.offset.y },
      { x: right(prevChild.nodeBounds),  y: prevChild.offset.y },
      { x: left(prevChild.branchBounds), y: bottom(prevChild.branchBounds) + REGION_EXPANSION_END }
    );
  }
}
```

```javascript
const NEAR_AXIS_THRESHOLD        = 20;   // 靠近主轴时的扩展阈值
const CHILDLESS_BRANCH_EXPANSION = 20;   // 无子节点分支的扩展
```

### 5.4 表格/矩阵结构的放置区域

对于表格（Grid/Matrix）布局，放置区域按单元格计算：

```javascript
function computeMatrixDropTargets(topicFigure) {
  const { topicId, matrixMetadata, branch } = topicFigure;
  const { secondaryHeads, cellById, contentTopicsForSecondaryHeadByIdForPrimaryHeadById } = matrixMetadata;

  const targets = [];

  for (const headId of secondaryHeads) {
    const cellBounds = boundsOfCellById[cellId];
    const cellTopics = contentTopicsForColumn[headId] ?? [];

    if (cellTopics.length > 0) {
      // 单元格有内容：在每个内容节点之间创建插入区域
      let prevInfo = null;
      for (const topicId of cellTopics) {
        const offset = offsetForChildTopicById[topicId];
        const insertionIndex = topicFigure.topicIndex;

        // 前一个节点到当前节点之间的区域
        const region = prevInfo
          ? boundingRect({ x: left(cellBounds), y: prevInfo.offset.y }, { x: right(cellBounds), y: offset.y })
          : boundingRect(topLeft(cellBounds), { x: right(cellBounds), y: offset.y });

        targets.push({ drop: { parentTopicId, insertionIndex, attributeChanges: { labels: cell.labels } }, region });
        prevInfo = { index: insertionIndex, offset, ... };
      }
      // 最后一个位置
      targets.push({ drop: ..., region: boundingRect(lastOffset, bottomRight(cellBounds)) });
    }
    else {
      // 空单元格：整个单元格都是放置区域
      targets.push({ drop: ..., region: cellBounds });
    }
  }

  return targets;
}
```

```javascript
    prevEdge = isColumnBased ? topOf(cellBounds) : leftOf(cellBounds);
  }

  // 最后一个位置的扩展区域
  const MATRIX_EXPANSION = 50;  // eO 常量
```

### 6.2 吸附点的计算

对于每个**非被拖拽的可见节点**，计算其 5 个吸附点：

```javascript
function computeAvailableTopicSnapPoints(topicFigure) {
  const bounds = getNodeBounds(topicFigure);
  return [
    { ...topLeft(bounds),     targetTopicId, targetBounds: bounds },  // 左上角
    { ...topRight(bounds),    targetTopicId, targetBounds: bounds },  // 右上角
    { ...bottomLeft(bounds),  targetTopicId, targetBounds: bounds },  // 左下角
    { ...bottomRight(bounds), targetTopicId, targetBounds: bounds },  // 右下角

}
```

```javascript
const sourcePoints = [

  topRight(draggedBounds),
```

### 6.3 吸附匹配

```javascript
function computeSnapTargets(startPoint, currentPoint, sheetFigure, sourceTopics, visibleArea, threshold) {
  const delta = subtract(currentPoint, startPoint);
  const draggedBounds = offsetBounds(unionBounds(sourceTopics), delta);

  // 收集所有可见非拖拽节点的吸附点
  const allTargetPoints = traverseTopicTree(sheetFigure, {
    prune: topic => topic.isOutOfScope || topic.ignoresChildrenTopicsForTopicSnapping
  }).filter(topic => !isBeingDragged(topic))
    .flatMap(topic => topic.computeAvailableTopicSnapPoints());

  const results = [];

  for (const sourcePoint of sourcePoints) {
    for (const targetPoint of allTargetPoints) {
      const dx = Math.abs(targetPoint.x - sourcePoint.x);
      const dy = Math.abs(targetPoint.y - sourcePoint.y);

      // X 轴对齐判定
      if (dx < threshold) {
        results.push({
          sourceBounds: draggedBounds,
          targetTopicId: targetPoint.targetTopicId,
          targetBounds: targetPoint.targetBounds,
          sourcePoint, targetPoint,
          snapOffset: { x: targetPoint.x - sourcePoint.x, y: 0 }  // 仅 X 方向吸附
        });
      }

      // Y 轴对齐判定
      if (dy < threshold) {
        results.push({
          sourceBounds: draggedBounds,
          targetTopicId: targetPoint.targetTopicId,
          targetBounds: targetPoint.targetBounds,
          sourcePoint, targetPoint,
          snapOffset: { x: 0, y: targetPoint.y - sourcePoint.y }  // 仅 Y 方向吸附
        });
      }
    }
  }

  // 按偏移量绝对值排序（最小偏移优先）
  return results.sort((a, b) => magnitude(a.snapOffset) - magnitude(b.snapOffset));
}
```

### 6.4 吸附偏移合成

从所有匹配的吸附结果中，分别取 X 方向和 Y 方向最优：

```javascript
function resolveSnapOffset(snapTargets) {
  if (!snapTargets) return null;

  // 找最佳 Y 方向吸附（snapOffset.x == 0 表示是 Y 方向对齐）
  const bestY = snapTargets.find(s => s.snapOffset.x === 0 && s.snapOffset.y !== 0);
  // 找最佳 X 方向吸附
  const bestX = snapTargets.find(s => s.snapOffset.y === 0 && s.snapOffset.x !== 0);

  if (!bestY && !bestX) return null;

  return {
    x: bestX?.snapOffset.x ?? 0,
    y: bestY?.snapOffset.y ?? 0
  };
}
```

### 6.5 吸附阈值常量

| 常量 | 值 | 含义 |
|------|---|------|
| `thresholdDistanceForTopicSnapping` | **10px**（`FB=10`） | 节点吸附判定距离 |
| `thresholdDistanceForBaselineSnapping` | **15px**（`Xs=15`） | 基线吸附判定距离 |
| `thresholdDifferenceForEscapingBaselineSnapping` | **5px**（`ec=5`） | 逃逸基线吸附所需的额外偏移 |

## 七、放置执行（Drop Commit）

### 7.1 `drop` 事件处理

```javascript
function handleDropEvent(state, sheetFigure) {
  const { startPoint, currentPoint, possibleDrop, shouldCopy, sourceTopics } = state.editSession;

  if (!possibleDrop) {
    // 无有效放置目标，取消拖拽
    return { editSession: null };
  }

  if (shouldCopy) {
    // Alt 键按下 → 复制模式
    const clonedTopics = cloneTopics(sourceTopics);

    if (possibleDrop === "detach" || possibleDrop === "freePosition") {
      // 自由放置：设置坐标
      applyPositionOffset(clonedTopics, subtract(currentPoint, startPoint));
      addAsDetachedChildren(sheet, clonedTopics);
    } else {
      // 作为子节点插入
      const { parentTopicId, insertionIndex, attributeChanges } = possibleDrop;
      if (attributeChanges) applyAttributes(clonedTopics, attributeChanges);
      insertChildren(parentTopicId, clonedTopics, insertionIndex);
    }
  } else {
    // 移动模式
    if (possibleDrop === "freePosition") {
      moveToFreePosition(sourceTopics, startPoint, currentPoint);
    }
    else if (possibleDrop === "detach") {
      detachToFloating(sourceTopics);
    }
    else {
      // 核心：作为子节点重新定位
      const { parentTopicId, insertionIndex, attributeChanges } = possibleDrop;
      moveToParent(sourceTopics, parentTopicId, insertionIndex, attributeChanges);
    }
  }
}
```

### 7.2 `moveToParent` — 作为子节点重新插入（含排序）

```javascript
function moveToParent(context, parentTopicId) {
  let sheet = context.sheet;
  const parentFigure = context.sheetFigure.topicFigureByTopicId[parentTopicId];

  // 计算有效插入索引（排除自身）
  const children = parentFigure.childrenTopics;
  let insertAt = context.at ?? children.length;

  // 如果父节点是折叠状态，插入到末尾并展开
  if (parentFigure.isBranchFolded) {
    insertAt = children.length;
    sheet = unfoldBranch(sheet, parentTopicId);
  }

  // 减去源节点自身在目标中的位置偏移
  insertAt -= children.filter((id, idx) =>
    idx < insertAt && context.topics.includes(id)
  ).length;

  // 从原位置移除
  sheet = removeFromParent(sheet, context.topics);

  // 应用属性变更（如表格的 labels）
  if (context.attributeChanges) {
    sheet = applyAttributes(sheet, context.topics, context.attributeChanges);
  }

  // 插入到新位置
  sheet = topic.asMovable({ parent: { id: parentTopicId }, at: insertAt }).move();

  return sheet;
}
```

```
└──────────────────────────────────────────┘
```

## 十、算法总结

### 完整拖拽流程

```
1. pointerdown → 记录起始位置
2. pointermove（>8px）→ 开始拖拽（lift）
3. pointermove（持续）→ 每帧执行：
   a. 计算鼠标在 sheet 坐标系中的位置
   b. 计算吸附偏移（对齐到其他节点的边/中心，阈值 10px）
   c. 应用吸附偏移到鼠标位置
   d. 从后向前遍历节点树，剪枝优化：
      - 如果鼠标不在分支的 droppableRegion 内，跳过整棵子树
   e. 对每个候选节点，遍历其 dropTargets（插入区域列表）
   f. 命中测试：鼠标是否在某个插入区域内
   g. 合法性检查：不能放到自己的子树中
   h. 确定 possibleDrop = { parentTopicId, insertionIndex }
   i. 渲染放置指示器
4. pointerup → 执行放置（drop）：
   a. 从原位置移除节点
   b. 计算有效插入索引（考虑自身位置偏移）
   c. 插入到新父节点的指定位置
   d. 重新布局渲染
```

### 关键设计要点

1. **区域预计算** — 每个节点的放置区域在布局阶段就计算好了（`dropTargets`），拖拽时只做命中测试，不做实时计算
2. **凸包合并** — 插入区域由相邻节点的边界框合并（`boundingRect`/`eo` 函数）得到
3. **剪枝优化** — 遍历树时用 `overallDroppableRegion` 做粗筛，避免遍历不相关的子树
4. **吸附是可选的** — 吸附偏移独立于放置目标计算，互不耦合
5. **树结构与表格结构共用一套框架** — 通过 `dropTargets` 的不同实现适配不同布局
