# 节点拖拽重排功能 — 实现规格

> 本文档是一份可直接照抄的功能规格，不依赖任何特定框架，描述纯粹的交互逻辑、数据结构和算法。

---

## 1. 数据结构

### 1.1 基础几何

```
Point   { x: number, y: number }
Rect    { x: number, y: number, width: number, height: number }
```

### 1.2 节点模型

```
Node {
  id: string
  parentId: string | null
  children: string[]          // 子节点 id 列表（有序）
  bounds: Rect                // 节点自身的渲染边界框
  branchBounds: Rect          // 节点 + 所有后代的整体边界框
  anchorPoint: Point          // 节点在画布上的锚点（绝对坐标）
}
```

### 1.3 放置目标

```
DropTarget {
  parentId: string            // 目标父节点 id
  insertionIndex: number      // 插入到第几个子节点位置（0-based）
  region: Rect                // 该放置位置对应的命中区域（相对于父节点锚点）
}
```

### 1.4 吸附结果

```
SnapResult {
  sourcePoint: Point          // 被拖拽节点的锚点
  targetPoint: Point          // 吸附到的目标点
  targetNodeId: string        // 目标节点 id
  snapOffset: Point           // 需要施加的偏移 { x: dx, y: 0 } 或 { x: 0, y: dy }
}
```

### 1.5 拖拽会话

```
DragSession {
  sourceNodeIds: string[]     // 被拖拽的节点 id 列表
  primaryNodeId: string       // 主拖拽节点（鼠标按下的那个）
  startPoint: Point           // 拖拽起始位置（画布坐标）
  currentPoint: Point         // 当前鼠标位置（画布坐标，含吸附偏移）
  possibleDrop: DropTarget | "detach" | null
  snapTargets: SnapResult[]   // 当前帧的吸附结果
  snapOffset: Point | null    // 最终合成的吸附偏移
}
```

## 2. 手势状态机

### 2.1 状态定义

```
DragGestureState = "idle" | "pressed" | "dragging"
```

### 2.2 状态转换

```
                        pointerdown
            idle ─────────────────────→ pressed
             ↑                            │
             │ pointerup                  │ pointermove (距离 > DRAG_THRESHOLD)
             │ (未达阈值)                  ↓
            pressed ←─────────────── dragging
                                          │
                                          │ pointerup
                                          ↓
                                     执行 drop → idle
```

### 2.3 核心实现

```
常量:
  DRAG_THRESHOLD = 8    // 移动超过 8px 才视为拖拽

全局状态:
  gestureState = "idle"
  pressPoint = null         // pointerdown 时记录的位置
  dragSession = null        // 拖拽会话

─────────────────────────────────────────

onPointerDown(event):
  pressPoint = toCanvasCoord(event)
  targetNode = hitTestNode(pressPoint)

  if targetNode == null:
    return

  gestureState = "pressed"
  event.target.setPointerCapture(event.pointerId)

─────────────────────────────────────────

onPointerMove(event):
  currentPoint = toCanvasCoord(event)

  if gestureState == "pressed":
    if distance(currentPoint, pressPoint) > DRAG_THRESHOLD:
      gestureState = "dragging"
      dragSession = createDragSession(targetNode, pressPoint)
      onDragStart(dragSession)

  else if gestureState == "dragging":
    onDragMove(dragSession, currentPoint)

─────────────────────────────────────────

onPointerUp(event):
  if gestureState == "dragging":
    onDragEnd(dragSession)

  gestureState = "idle"
  pressPoint = null
  dragSession = null
  event.target.releasePointerCapture(event.pointerId)
```

## 3. 拖拽启动

```
function createDragSession(targetNode, startPoint):
  // 收集被拖拽的节点（如果有多选，全部带上）
  selectedNodes = getSelectedNodes()
  if targetNode.id not in selectedNodes:
    selectedNodes = [targetNode.id]

  // 过滤：只拖拽非根节点
  draggableNodes = selectedNodes.filter(id =>
    getNode(id).parentId != null
  )

  if draggableNodes.length == 0:
    return null

  return {
    sourceNodeIds: draggableNodes,
    primaryNodeId: targetNode.id,
    startPoint: startPoint,
    currentPoint: startPoint,
    possibleDrop: null,
    snapTargets: [],
    snapOffset: null,
  }
```

## 4. 拖拽过程（每帧执行）

```
function onDragMove(session, rawPoint):
  // ──── 步骤1: 吸附计算 ────
  snapResult = computeSnap(session, rawPoint)
  session.snapTargets = snapResult.targets
  session.snapOffset = snapResult.offset

  // ──── 步骤2: 应用吸附偏移 ────
  snappedPoint = {
    x: rawPoint.x + (snapResult.offset?.x ?? 0),
    y: rawPoint.y + (snapResult.offset?.y ?? 0),
  }
  session.currentPoint = snappedPoint

  // ──── 步骤3: 查找放置目标 ────
  session.possibleDrop = findDropTarget(snappedPoint, session.sourceNodeIds)

  // ──── 步骤4: 更新视觉 ────
  renderDragGhost(session)            // 渲染拖拽幽灵
  renderDropIndicator(session)        // 渲染放置指示器
  renderSnapGuides(session)           // 渲染吸附参考线
```

## 5. 放置目标查找算法

### 5.1 总体流程

```
function findDropTarget(point, sourceNodeIds):
  allNodes = getAllNodes()

  // 从后向前遍历（越晚渲染的越优先被命中）
  for node in reversed(allNodes):

    // ──── 剪枝 ────
    // 如果鼠标不在该节点分支区域内，跳过
    if not pointInRect(point, node.branchBounds):
      continue

    // ──── 跳过不可接收子节点的节点 ────
    if not node.canHaveChildren:
      continue

    // ──── 遍历该节点的放置区域列表 ────
    for target in node.dropTargets:
      absoluteRegion = offsetRect(target.region, node.anchorPoint)

      if pointInRect(point, absoluteRegion):

        // ──── 合法性检查 ────
        if isValidDrop(sourceNodeIds, target):
          return target

  return null
```

### 5.2 合法性检查

```
function isValidDrop(sourceNodeIds, target):
  for nodeId in sourceNodeIds:
    // 规则1: 不能放到自己下面
    if nodeId == target.parentId:
      return false

    // 规则2: 不能放到自己的后代下面（防止循环）
    if isDescendantOf(target.parentId, nodeId):
      return false

  return true
```

### 5.3 pointInRect

```
function pointInRect(point, rect):
  return point.x >= rect.x
      && point.x <= rect.x + rect.width
      && point.y >= rect.y
      && point.y <= rect.y + rect.height
```

## 6. 放置区域预计算

### 6.1 何时计算

放置区域在**布局阶段**计算好，挂在每个节点上。每次布局完成后更新。拖拽过程中不重新计算——只做命中测试。

```
function layoutComplete(node):
  node.dropTargets = computeDropTargets(node)
```

### 6.2 计算逻辑

```
常量:
  EXPANSION_FIRST  = 30    // 第一个位置上方的扩展
  EXPANSION_LAST   = 20    // 最后一个位置下方的扩展
  EXPANSION_EMPTY  = 20    // 无子节点时的扩展

─────────────────────────────────────────

function computeDropTargets(parentNode):
  children = parentNode.children.map(id => getNode(id))
  spacing = parentNode.childSpacing    // 子节点之间的间距

  // ──── 无子节点 ────
  if children.length == 0:
    region = createEmptyRegion(parentNode, spacing)
    return [{ parentId: parentNode.id, insertionIndex: 0, region }]

  // ──── 有子节点：为 N 个子节点创建 N+1 个放置区域 ────
  targets = []

  for i in 0 .. children.length:    // 含两端，共 N+1 个
    prev = children[i - 1] if i > 0 else null
    next = children[i] if i < children.length else null

    region = computeInsertionRegion(prev, next, parentNode)

    targets.push({
      parentId: parentNode.id,
      insertionIndex: i,
      region: region,
    })

  return targets
```

### 6.3 插入区域的几何计算

以**树向右生长、子节点从上到下排列**为例（最常见的思维导图布局）：

```
function computeInsertionRegion(prev, next, parent):
  parentRight = parent.bounds.x + parent.bounds.width

  if prev != null && next != null:
    // ──── 两个子节点之间 ────
    //
    //   prev ──────┐
    //              │  ← 这个区域
    //   next ──────┘
    //
    midY = (bottom(prev.branchBounds) + top(next.branchBounds)) / 2
    return {
      x: parentRight,
      y: bottom(prev.branchBounds),
      width: max(right(prev.branchBounds), right(next.branchBounds)) - parentRight,
      height: top(next.branchBounds) - bottom(prev.branchBounds),
    }

  else if next != null && prev == null:
    // ──── 第一个位置（最上方） ────
    //
    //        ← 扩展区域
    //   next ──────
    //
    return {
      x: parentRight,
      y: top(next.branchBounds) - EXPANSION_FIRST,
      width: right(next.branchBounds) - parentRight,
      height: EXPANSION_FIRST,
    }

  else if prev != null && next == null:
    // ──── 最后一个位置（最下方） ────
    //
    //   prev ──────
    //        ← 扩展区域
    //
    return {
      x: parentRight,
      y: bottom(prev.branchBounds),
      width: right(prev.branchBounds) - parentRight,
      height: EXPANSION_LAST,
    }
```

### 6.4 可视化示意

```
假设父节点有 3 个子节点 A、B、C：

                    insertionIndex=0 的区域
                    ┌─────────────────────────┐
                    │    (A 上方 30px 扩展)     │
  ┌──────────┐      ├─────────────────────────┤
  │          │      │                         │
  │  父节点   │──────│     子节点 A 的分支       │
  │          │      │                         │
  └──────────┘      ├─────────────────────────┤

                    ├─────────────────────────┤
                    │                         │
                    │     子节点 B 的分支       │
                    │                         │
                    ├─────────────────────────┤
                    │  insertionIndex=2 的区域  │ ← B 底部 ~ C 顶部
                    ├─────────────────────────┤
                    │                         │
                    │     子节点 C 的分支       │
                    │                         │

                    │    (C 下方 20px 扩展)     │
                    └─────────────────────────┘
```

## 7. 吸附算法

### 7.1 吸附概述

拖拽节点时，当被拖拽节点的边/中心与画布上其他节点的边/中心接近时，自动对齐并显示参考线。

X 方向和 Y 方向独立计算，互不干扰。

### 7.2 吸附锚点

每个节点提供 **5 个吸附锚点**：

```
function getSnapAnchors(node):
  b = node.bounds
  return [
    { x: b.x,                 y: b.y                  },  // 左上
    { x: b.x + b.width,       y: b.y                  },  // 右上
    { x: b.x,                 y: b.y + b.height       },  // 左下
    { x: b.x + b.width,       y: b.y + b.height       },  // 右下
    { x: b.x + b.width / 2,   y: b.y + b.height / 2   },  // 中心
  ]
```

被拖拽的节点也取自身边界框的同样 5 个点（多节点时取合并边界框的 4 个角点）。

### 7.3 吸附匹配算法

```
常量:
  SNAP_THRESHOLD = 10    // 距离小于 10px 时触发吸附

─────────────────────────────────────────

function computeSnap(session, rawPoint):
  delta = subtract(rawPoint, session.startPoint)
  draggedBounds = offsetRect(
    unionBounds(session.sourceNodeIds.map(id => getNode(id).bounds)),
    delta
  )
  sourceAnchors = getSnapAnchors(draggedBounds)

  // 收集所有非拖拽节点的锚点
  targetAnchors = []
  for node in getAllVisibleNodes():
    if node.id in session.sourceNodeIds:
      continue
    for anchor in getSnapAnchors(node):
      targetAnchors.push({ ...anchor, nodeId: node.id })

  // 匹配
  matches = []
  for src in sourceAnchors:
    for tgt in targetAnchors:
      dx = abs(tgt.x - src.x)
      dy = abs(tgt.y - src.y)

      if dx < SNAP_THRESHOLD:
        matches.push({
          sourcePoint: src,
          targetPoint: tgt,
          targetNodeId: tgt.nodeId,
          snapOffset: { x: tgt.x - src.x, y: 0 },
        })

      if dy < SNAP_THRESHOLD:
        matches.push({
          sourcePoint: src,
          targetPoint: tgt,
          targetNodeId: tgt.nodeId,
          snapOffset: { x: 0, y: tgt.y - src.y },
        })

  // 按偏移绝对值排序
  matches.sort((a, b) => magnitude(a.snapOffset) - magnitude(b.snapOffset))

  // 合成最终偏移：X 和 Y 各取最优
  bestX = matches.find(m => m.snapOffset.y == 0 && m.snapOffset.x != 0)
  bestY = matches.find(m => m.snapOffset.x == 0 && m.snapOffset.y != 0)
  offset = null
  if bestX or bestY:
    offset = {
      x: bestX?.snapOffset.x ?? 0,
      y: bestY?.snapOffset.y ?? 0,
    }

  return { targets: matches, offset: offset }
```

### 7.4 吸附参考线渲染

```
function renderSnapGuides(session):
  if session.snapTargets.length == 0:
    hideAllGuides()
    return

  // X 方向对齐 → 画竖线
  xSnap = session.snapTargets.find(m => m.snapOffset.y == 0)
  if xSnap:
    drawVerticalLine(
      x: xSnap.targetPoint.x,
      y1: min(xSnap.sourcePoint.y, xSnap.targetPoint.y) - 20,
      y2: max(xSnap.sourcePoint.y, xSnap.targetPoint.y) + 20,
      color: "#2EBDFF",
      dashPattern: [4, 4],
    )

  // Y 方向对齐 → 画横线
  ySnap = session.snapTargets.find(m => m.snapOffset.x == 0)
  if ySnap:
    drawHorizontalLine(
      y: ySnap.targetPoint.y,
      x1: min(ySnap.sourcePoint.x, ySnap.targetPoint.x) - 20,
      x2: max(ySnap.sourcePoint.x, ySnap.targetPoint.x) + 20,
      color: "#2EBDFF",
      dashPattern: [4, 4],
    )
```

## 8. 拖拽放置执行

### 8.1 drop 总入口

```
function onDragEnd(session):
  drop = session.possibleDrop

  // 没有有效目标 → 取消
  if drop == null:
    cancelDrag(session)
    return

  // 执行放置
  commitDrop(session, drop)

  // 清理视觉
  hideDragGhost()
  hideDropIndicator()
  hideSnapGuides()
```

### 8.2 commitDrop

```
function commitDrop(session, drop):
  sourceIds = session.sourceNodeIds

  // ──── 计算有效插入索引 ────
  targetParent = getNode(drop.parentId)
  insertAt = drop.insertionIndex

  // 如果拖到同一个父节点内，需要修正索引
  // （因为源节点移除后，后续节点的索引会前移）
  sameParentCount = 0
  for i in 0 .. insertAt:
    if targetParent.children[i] in sourceIds:
      sameParentCount += 1
  insertAt -= sameParentCount

  // ──── 从旧位置移除 ────
  for nodeId in sourceIds:
    oldParent = getNode(getNode(nodeId).parentId)
    oldParent.children.remove(nodeId)

  // ──── 插入到新位置 ────
  targetParent.children.insertAll(insertAt, sourceIds)

  // ──── 更新父子关系 ────
  for nodeId in sourceIds:
    getNode(nodeId).parentId = drop.parentId

  // ──── 触发重新布局 ────
  relayout()
```

### 8.3 索引修正示意

```
场景：父节点有子节点 [A, B, C, D]，拖拽 B 到 index=3（D 之后）

原始状态:   A(0)  B(1)  C(2)  D(3)
                  ↑ 被拖拽

目标 insertionIndex = 3（D 之后的位置）

步骤1: 计算修正
  - B 在 index=1，小于目标 index=3
  - sameParentCount = 1
  - 有效 insertAt = 3 - 1 = 2

步骤2: 移除 B
  剩余: A(0)  C(1)  D(2)

步骤3: 在 index=2 处插入 B
  结果: A(0)  C(1)  B(2)  D(3)

→ 最终效果：B 从 C 前面移到了 C 后面 ✓
```

## 9. 视觉反馈

### 9.1 拖拽幽灵（Drag Ghost）

```
function renderDragGhost(session):
  delta = subtract(session.currentPoint, session.startPoint)

  for nodeId in session.sourceNodeIds:
    node = getNode(nodeId)
    ghostRect = offsetRect(node.bounds, delta)

    drawRect(
      rect: ghostRect,
      fillColor: "rgba(节点颜色, 0.5)",   // 半透明
      borderColor: "#2EBDFF",
      borderWidth: 1,
      opacity: 0.6,
    )
```

### 9.2 放置指示器（Drop Indicator）

```
常量:
  INDICATOR_WIDTH  = 50
  INDICATOR_HEIGHT = 18
  INDICATOR_RADIUS = 4
  INDICATOR_COLOR  = "#2EBDFF"   // rgb(46, 189, 255)

─────────────────────────────────────────

function renderDropIndicator(session):
  drop = session.possibleDrop

  if drop == null:
    hideDropIndicator()
    setCursor("no-drop")
    return

  setCursor("grabbing")

  parentNode = getNode(drop.parentId)
  children = parentNode.children.map(id => getNode(id))
  insertAt = drop.insertionIndex

  // 计算指示器位置
  if insertAt == 0 && children.length > 0:
    // 在第一个子节点之前
    firstChild = children[0]
    indicatorY = top(firstChild.bounds) - INDICATOR_HEIGHT / 2
    indicatorX = left(firstChild.bounds)

  else if insertAt >= children.length:
    // 在最后一个子节点之后
    lastChild = children[children.length - 1]
    indicatorY = bottom(lastChild.bounds) - INDICATOR_HEIGHT / 2
    indicatorX = left(lastChild.bounds)

  else:
    // 在两个子节点之间
    prevChild = children[insertAt - 1]
    nextChild = children[insertAt]
    indicatorY = (bottom(prevChild.bounds) + top(nextChild.bounds)) / 2 - INDICATOR_HEIGHT / 2
    indicatorX = min(left(prevChild.bounds), left(nextChild.bounds))

  // 绘制圆角矩形
  drawRoundedRect(
    x: indicatorX,
    y: indicatorY,
    width: INDICATOR_WIDTH,
    height: INDICATOR_HEIGHT,
    radius: INDICATOR_RADIUS,
    fillColor: INDICATOR_COLOR,
  )

  // 绘制连接线（从父节点到指示器）
  drawLine(
    from: { x: right(parentNode.bounds), y: centerY(parentNode.bounds) },
    to: { x: indicatorX, y: indicatorY + INDICATOR_HEIGHT / 2 },
    color: INDICATOR_COLOR,
    width: 2,
  )
```

## 10. 事件绑定汇总

```
画布层 (canvas / viewport):
  pointerdown   → 记录按下位置，确定目标节点
  pointermove   → 判断是否启动拖拽 / 更新拖拽状态
  pointerup     → 执行放置 / 清理状态
  pointerleave  → 取消拖拽（鼠标移出画布）

document 层:
  keydown       → 检测 Escape 取消拖拽
```

## 11. 性能优化要点

1. **放置区域预计算** — 在 `layout()` 完成后计算好 `dropTargets` 挂在节点上，拖拽过程中零开销
2. **剪枝遍历** — 查找放置目标时，用 `branchBounds` 做粗筛，鼠标不在范围内直接跳过整棵子树
3. **吸附延迟** — 如果节点数量大（>100），可以只对可视区域内的节点做吸附计算
4. **requestAnimationFrame** — `onDragMove` 内的视觉更新用 rAF 节流，避免每个 pointermove 都触发渲染
5. **setPointerCapture** — 在 pointerdown 时调用，保证 pointermove/up 即使鼠标移出元素也能收到

---

## 12. 注意事项

1. **不是"交换"，是"重新插入"** — 拖拽节点到新位置时，不是两个节点互换，而是源节点从原位置移除后插入到目标位置的指定索引
2. **索引修正** — 同一父节点内移动时，源节点的移除会影响后续节点的索引，必须先修正 `insertionIndex`
3. **不能放到自己的后代中** — 合法性检查必须遍历祖先链，防止产生循环
4. **根节点不可拖拽** — 没有 parentId 的节点不参与拖拽
5. **吸附与放置解耦** — 吸附只影响视觉位置（幽灵/参考线），放置目标的命中测试使用吸附后的位置
6. **多选拖拽** — 多个节点同时拖拽时，它们保持相对位置，作为一组执行插入
