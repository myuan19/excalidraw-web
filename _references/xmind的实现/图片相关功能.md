# Xmind 图片相关功能 — 逆向分析

## 一、图片数据模型

Topic（节点）的图片属性定义在 `renderer/3373.js` 中，每个 topic 拥有以下图片相关字段：

```javascript
// Topic 数据模型（简化后）
{
  image: {
    src: "xap:resources/sha256hash.png",  // 图片来源，xap: 前缀指向 .xmind 包内资源
    align: "top",                          // 对齐方式
    width: 200,                            // 宽度
    height: 150                            // 高度
  },
  imageSource: "...",       // 图片资源路径（运行时用的视图层属性）
  imageWidth: null,         // 图片宽度
  imageHeight: null,        // 图片高度
  imageLockRatio: true,     // 锁定宽高比（默认锁定）
  imagePlacement: "top",    // 图片相对于文字的位置
  imageBorderLineColor: null,
  imageBorderLineWidth: null,
  imageShadowVisible: null,
  imageOpacity: null,
  imageIsMathJaxImage: false
}
```

核心在 `renderer/7744.js`（约 3.3MB 的渲染引擎）中读取这些属性。

## 二、图片位置（Placement）

图片相对于节点文字的位置由 `imagePlacement` 控制，使用枚举 `Po`：

```javascript
// 默认值是 Po.Top（图片在文字上方）
imageViewPlacement: e => e.topicFigure.modelAttributes.imagePlacement ?? Po.Top

// 四个可选位置
Po.Top     // 图片在文字上方（默认）
Po.Bottom  // 图片在文字下方
Po.Left    // 图片在文字左边
Po.Right   // 图片在文字右边
```

布局逻辑（`7744.js`）：
- 当 `placement` 为 Top 或 Bottom 时，图片和文字垂直排列
- 当 `placement` 为 Left 或 Right 时，图片和文字水平排列

```javascript
// 判断是垂直还是水平布局
const isVertical = placement === Po.Top || placement === Po.Bottom;

// 垂直布局（上下排列）
if (isVertical) {
  view = verticalStack(
    placement === Po.Top
      ? [{ view: imageView, bottom: spacing }, ...textViews]
      : [...textViews, { view: imageView, bottom: spacing }],
    { id, align, preferredWidth }
  );
}
// 水平布局（左右排列）
else {
  view = horizontalStack(
    placement === Po.Left
      ? [{ view: imageView, right: spacing }, { view: textView }]
      : [{ view: textView, right: textView?.width ? spacing : 0 }, { view: imageView }],
    { id }
  );
}
```

**结论：默认图片在文字上方（Po.Top），这符合你描述的 "图片位于单元格上方区域"。**

拖拽调整位置时，渲染引擎将节点区域划分为四个象限区域：

```javascript
// 拖拽时计算四个放置区域
[
  { placement: Po.Left,   region: { x, y, width, height } },
  { placement: Po.Top,    region: { x, y, width, height } },
  { placement: Po.Bottom, region: { x, y, width, height } },
  { placement: Po.Right,  region: { x, y, width, height } }
]
```

**通过拖拽图片到不同区域来改变位置，而非通过顶部位置选择栏。**

## 三、粘贴图片（Ctrl+V）

核心代码位于 `renderer/7222.js`：

```javascript
clipboard: {
  read: async function () {
    const isFromCloud = getContexts()["collaboration.isFromCloud"];
    const text = await clipboard.readText("clipboard");
    const html = await clipboard.readHTML("clipboard");

    const files = await (async function () {
      let filePaths = [];

      // Windows：通过 CF_HDROP 读取文件路径
      if (clipboard.has("CF_HDROP")) {
        const buffer = clipboard.readBuffer("CF_HDROP").toString("ucs2");
        // 解析 UCS-2 编码路径列表...
        filePaths = parsedPaths;
      } else {
        // macOS/Linux：通过 FileNameW 读取
        filePaths = [clipboard.readBuffer("FileNameW")
          .toString("ucs2")
          .replace(/\0/g, "")]
          .filter(p => p);
      }

      // 将文件路径转为 File 对象
      const fileObjects = [];
      for (const filePath of filePaths) {
        const name = path.basename(filePath);
        const mimeType = mime.getType(path.extname(filePath).substring(1));
        const data = await fs.readFile(filePath);
        fileObjects.push(new File(
          [new Blob([data.buffer], { type: mimeType })],
          name, { type: mimeType }
        ));
      }

      // 如果没有文件路径，从剪贴板直接读取图片
      if (fileObjects.length === 0) {
        const img = clipboard.readImage();
        if (!img.isEmpty()) {
          fileObjects.push(new File(
            [new Blob([img.toPNG().buffer], { type: "image/png" })],
            "Untitled.png", { type: "image/png" }
          ));
        }
      }

      return fileObjects;
    })();

    // 图片大小检查（云端协作场景）
    if (files.some(f => f.type.startsWith("image"))) {
      const oversized = files.some(f => f.type.startsWith("image") && f.size > IMAGE_SIZE_LIMIT);
      if (isFromCloud && oversized) {
        await showDialog("upload-limit-exceeded-of-image");
        return { text: null, html: null };
      }
    }

    return { text, html, files };
  },

  // 写入剪贴板
  write: async (data) => {
    const buffer = await data.image?.arrayBuffer();
    const nativeImg = buffer
      ? nativeImage.createFromBuffer(Buffer.from(buffer))
      : null;
    return clipboard.write({
      text: data.text,
      html: data.html,
      image: nativeImg
    }, "clipboard");
  }
}
```

### 粘贴流程

1. Ctrl+V → 编辑器触发 paste 命令
2. 调用 `clipboard.read()` 读取剪贴板
3. 优先读取文件路径（CF_HDROP / FileNameW），再尝试 `clipboard.readImage()`
4. 图片转为 PNG 的 File 对象
5. 云端协作时做大小限制检查
6. 返回 `{ text, html, files }` 给编辑器引擎处理

### 关于编辑状态下能否粘贴

从命令注册来看（`common.js`），`editor.addLocalImage` 和 `editor.changeImage` 都被注册为编辑器命令：

```javascript
// common.js 中的编辑器命令列表
[
  "editor.changeImage",
  "editor.addMarker",
  "editor.addLocalImage",
  ...
]
```

粘贴命令 `paste` 在编辑器和大纲模式下都标记为支持：

```javascript

```

## 五、图片预览（放大查看）

触发条件（`renderer/7750.js`）：

```javascript
// 点击已选中的图片 → 触发预览
if (topic.imageSource) {
  handleCommand("editor.previewImage", { topicId: topic.topicId });
}
```

预览窗口是独立的 Electron 窗口（`renderer/image-viewer.html` + `image-viewer.js`），通过 IPC 通信传递图片 URL：

```javascript
// common.js 中的 IPC 路由
"POST /image-viewer/openUrl"
```

**图片预览的触发方式：选中包含图片的 topic 后，再次点击图片区域即可打开预览。**
在 editor.js 中，`editor.previewImage` 命令的启用条件是 `!selection.hasImageLoadingFailed`（图片未加载失败时可用）。

## 六、图片存储格式

图片在 `.xmind` 文件中的存储方式（`renderer/2601.js`）：

```javascript
// .xmind 文件本质是 ZIP 包，图片存储在 resources/ 目录
// 文件名为内容的 SHA256 哈希值
const hash = SHA256.create().update(imageData).finalize().toString(Hex);
const filePath = "resources/" + hash + "." + extension;

// 在 content.json 中引用
topic.image = {
  src: "xap:" + filePath,  // xap: 协议前缀
  align: "top",
  width: 200,
  height: 150
};
```

图片也可以是外链 HTTP 图片：

```javascript
if (url.split(":")[0].startsWith("http")) {
  topic.image = { src: url, align, width, height };
}
```

## 七、总结：你描述的功能 vs Xmind 实现

| 你的需求 | Xmind 实现 | 匹配度 |
|---------|-----------|--------|
| Ctrl+V 粘贴图片 | 支持，clipboard.read() → nativeImage / File | ✅ 完全匹配 |
| 单击选中和双击编辑都能粘贴 | paste 命令在选中和编辑模式下都注册 | ✅ 支持 |
| 默认图片在上方 | imagePlacement 默认 Po.Top | ✅ 完全匹配 |
| 拖拽调整位置 | 拖拽到四象限区域切换 Top/Bottom/Left/Right | ✅ 拖拽方式 |
| 不显示顶部位置选择栏 | 通过拖拽调整，不是选择栏 | ✅ 一致 |
| 选中图片后的右键菜单 | Preview / Copy / Cut / Paste / Delete / Save as / Reset Size | ✅ 有独立菜单 |
| 快捷键操作图片 | Ctrl+C/X/V、Delete/Backspace、Space预览 | ✅ 完全支持 |
| 无右上角删除图标 | 大纲模式用右键/快捷键删除，思维导图模式用 Remove 子菜单 | ✅ 无浮动删除按钮 |
| 再次点击放大预览 | editor.previewImage → 独立窗口 | ✅ 完全匹配 |

**补充发现：**
- Xmind 还支持图片**边框**（颜色、宽度）和**阴影**效果
- 图片有**透明度**（opacity）控制
- 图片支持**锁定宽高比**（默认锁定）
- 支持**全选所有图片**（selectAllImages）
- 图片来源安全检查：对 HTTP 外链图片会弹出安全警告，需用户确认"Load Anyway"才加载
- 支持**图片另存为**本地文件
- 支持**重置图片大小**回原始尺寸
