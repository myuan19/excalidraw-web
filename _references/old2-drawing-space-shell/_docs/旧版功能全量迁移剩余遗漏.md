# 旧版功能全量迁移剩余遗漏

## v0.2.7 已补齐

- **CommandPalette**：`MainMenu.DefaultItems.CommandPalette`（发布包通过 DefaultItems 导出，非顶层符号）。
- **TTD 会话 UI**：`TtdChatPanel` 对话框（列表 / 查看 / 删除 / Mermaid 插入画布），替代仅侧车 `TtdPromptHistory`。
- **素材库 URL 导入建组**：`useHandleLibrary` + `excalidrawLibraryAdapter` + `autoCreateGroupFromUrlImport`。
- **素材库 groups 持久化**：`CombinedLibraryAdapter` 缓存 groups，避免 `onLibraryChange` 覆盖分组。
- **契约测试**：`normalizeDomains`、`embedTokenActiveCache`、`mindMapThumbnailSvg`、`libraryUrlGroups`、`extractMermaid`。
- **API smoke**：`_scripts/smoke-api.mjs`。
- **测试**：Vitest 增至 48+ 项（以 `yarn test` 为准）。

## v0.2.6 及更早（摘要）

URL 深链、保存 skipped、本地场景缓存、MindMap 缩略图、Text 主题、导入回滚、Delta onIncrement、Embed 域名测试等见 git 历史与本文件 v0.2.6 段落。

## 仍受上游或范围限制

### TTD 对话框内嵌会话列表

内置 `TTDDialog` 仍无 `persistenceAdapter`；完整会话在独立 `TtdChatPanel` 中管理，非弹窗内 Tab。

### 素材库 LibraryGroupEnhancer 全量

库内拖拽排序、面板内分组 DOM 增强、库 undo/redo 快捷键未 1:1 迁入（依赖 `setLibraryGroups` / 旧 fork 面板脚本）。

### Excalidraw  durable undo

`onIncrement` 写入 `DeltaStorage` 快照，非旧版 `StoreDelta` 撤销栈恢复。

### 部署与 E2E

HTTPS、反向代理、`frame-ancestors`、跨域 iframe、token 多进程 cache 需真实环境手测。

### 旧版测试全集

部分旧应用/服务端测试未回迁；新架构单元/smoke 已覆盖核心契约。

## 建议手测清单（发布前）

见 `_docs/旧版功能全量迁移矩阵.md` 文末「端到端手测必须覆盖」一节。
