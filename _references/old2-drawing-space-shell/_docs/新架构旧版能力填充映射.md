# 新架构旧版能力填充映射

## 一、当前新架构槽位

| 槽位 | 当前目录 | 职责 | 迁移原则 |
|---|---|---|---|
| 应用基座 | `src/components/app/*` | 左侧导航、右侧页面/编辑器容器、平台工具栏、历史/嵌入入口 | 所有编辑器共用的返回、保存、历史、嵌入、AI 设置入口放这里 |
| 文件基座 | `src/features/files/*`、`src/pages/FilesPage.tsx` | 文件/文件夹 UI、导入、移动、卡片、搜索、缩略图展示 | 只承载文件系统体验，不嵌入编辑器私有逻辑 |
| 编辑器插件 | `src/editors/{excalidraw,mindmap,text}`、`src/features/editor/*` | 实现 `EditorAdapter`，负责 mount/load/save/thumbnail/change | 编辑器私有菜单、bridge、渲染细节放各编辑器目录 |
| 文档格式层 | `src/features/documents/*` | `ManagedDocument`、格式识别、迁移、导入/下载序列化 | 所有保存、导入、下载、历史恢复最终走 adapter |
| 同步与草稿 | `src/features/sync/*` | `FileSyncState`、`LocalDraftStorage`、autosave、Delta/LocalData/browser scene | 旧版 `DeltaStorage`、`LocalData`、fork browser scene 都归这里 |
| 缩略图 | `src/features/thumbnail/*` | 本地/服务端缩略图、预取、选择策略、SVG 工具 | 编辑器产出缩略图，基座负责缓存、预取、列表选择 |
| 设置 | `src/features/settings/*`、`src/pages/SettingsPage.tsx` | AI 配置、外观语言、Embed 管理、素材库入口 | 配置类 UI 和跨编辑器共享管理入口放这里 |
| AI 运行时 | `src/features/ai/*` | OpenAI-compatible streaming、TTD、Diagram-to-Code、错误提示、前端日志 | 浏览器直连用户配置的 Base URL，不混入 server |
| 素材库 | `src/features/library/*` | public/personal/canvas 三层合并、同步队列、Excalidraw 接线、本地 mirror | 先保证可持久化和离线读回，再评估 fork 包增强 |
| 后端服务 | `server/routes/*`、`server/db.js` | SQLite 持久化、files/library/ai/embed/archive/logs/ttd | 后端保持资源 API，复杂 UI 状态留前端 |

## 三、执行顺序

1. **数据安全先闭环**：`FileSyncState`、`openFileSync`、`DeltaStorage`、`LocalData`、browser scene、离开确认、beforeunload、单测。
2. **编辑器平台入口收口**：AppShell 工具栏、Ctrl/⌘+S、保存状态、历史/Embed/AI/返回统一入口。
3. **MindMap bridge 补齐**：view storage、save status、AI payload、完整 clipboard、hostOpen* 手测、native 保存落盘。
4. **Excalidraw Shell 补齐**：MainMenu、Welcome、Footer、CommandPalette；AI/素材库只挂入口，不在此轮硬塞。
5. **AI/TTD 运行时**：`features/ai`、OpenAI streaming、TTD persistence、未配置提示、设置订阅；D2C 和 icon tag UI 继续补齐。
6. **素材库 MVP**：CombinedLibraryAdapter、librarySyncQueue、public/personal/canvas 三层持久化、groups payload、本地 mirror；分组增强和 AI 打标继续评估 fork/patch。
7. **后端与测试收口**：db smoke、API smoke、Embed 测试、React warnings、文档矩阵和 log。

## 四、完成判定

- 每个旧版能力必须在上表有明确新架构落点。
- 每个落点至少有一个可运行验证：单测、typecheck、build、server syntax、或明确手测记录。
- 不能因为源码存在就判定完成；必须能通过 UI 或 API 真实操作。
- 若受第三方包限制不能等价迁移，必须在本文和迁移矩阵注明降级策略。
