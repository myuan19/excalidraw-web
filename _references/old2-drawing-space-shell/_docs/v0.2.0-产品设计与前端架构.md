### 5.3 编辑器视图 (activeView === "editor")

**核心行为**：编辑器 DOM 始终挂载，切换到其他视图（文件管理/设置）时编辑器**不卸载**，
仅通过 `display:none` / `visibility:hidden` 隐藏。切回时立即恢复，无重载开销。

#### 文件夹树 — 完整迁移旧版逻辑

**数据结构**（扁平数组 + `parent_id`，与旧版一致）：

```typescript
interface ServerFolder {
  id: string;
  parent_id: string | null;
  name: string;
  sort_index: number;
  created_at: string;
  updated_at: string;
}
```

**功能完整清单**（全部从旧版迁移）：

| 功能 | 实现方式 |
|------|----------|
| 递归渲染 | `renderFolderTree(parentId, depth)` 按 `parent_id` 筛子节点 |
| 展开/折叠 | `expandedFolders: Record<string, boolean>`，默认展开 |
| 缩进 | `paddingLeft: 0.35 + depth * 0.75 rem` |
| **拖拽排序/嵌套** | 原生 HTML5 DnD，MIME: `application/x-folder-dnd` |
| 拖放模式 | 指针在行内 1/3 位置判定: `before` / `into` / `after` |
| 防循环 | `isValidFolderDrop` — 禁止拖入自身或子孙 |
| 落定后持久化 | `ServerSync.saveOrder(parentId, items)` → `POST /files/order` |
| 新建文件夹 | 在当前文件夹下创建子文件夹，自动展开父级 |
| 重命名 | 行内编辑 → `ServerSync.renameFolder` |
| 删除 | confirm → 文件移到根目录、子文件夹删除 |
| 选中导航 | 点击 → `setCurrentFolder(id)`，面包屑联动 |
| 移动端 | sidebar 隐藏，通过 Sheet 抽屉打开 |

**Drop 指示器样式**：
- `before/after`: 顶部/底部蓝色指示线
- `into`: 行背景高亮 `accent-soft`

**缩略图尺寸调整**（相比旧版调小）：

| 参数 | 旧版值 | 新值 | 说明 |
|------|--------|------|------|
| `aspect-ratio` | `5/3` | `5/3` | 保持不变 |
| `max-height` | `clamp(6rem, 13vw, 8.25rem)` | `clamp(5rem, 10vw, 6.5rem)` | 缩小约 20% |

## 九、设计原则

| 原则 | 说明 |
|------|------|
| **Sidebar 常驻** | 无论当前处于哪个视图（含全屏编辑器），左侧 72px 导航栏始终可见 |
| **编辑器不卸载** | 编辑器一旦 mount 就保持活跃；切换到文件/设置页时仅 `display:none`，不触发 unmount，回来时零延迟恢复 |
| **编辑器可插拔** | 实现 `EditorAdapter` 接口即可注册，无需修改平台代码 |
| **逻辑直接迁移** | 文件夹树 DnD、缩略图管道、文件同步等旧版逻辑直接迁移，仅改样式适配 Tailwind token |
| **服务端持久化** | 文件数据和 AI 配置存服务端 SQLite，无需"云端同步"功能 |
| **配置统一** | AI 配置、外观、嵌入管理等全部收拢到「设置页」 |
| **文件格式无关** | 平台层只关心 Blob 和元信息，格式解析由对应编辑器负责 |
| **渐进增强** | 初始阶段可不接入任何编辑器，仅作为文件管理入口 |
