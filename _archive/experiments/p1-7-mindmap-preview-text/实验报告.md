# 实验报告: MindMap 预览文字规范化

## 问题描述

MindMap 首页预览图里，节点文字显示成 `&lt;p&gt;写网页&lt;/p&gt;`、`&lt;p&gt;&lt;br&gt;&lt;/p&gt;` 这类 HTML 标签字符，而不是正常文字。

## 问题原因

已有缩略图 SVG 的 `<text>` 节点保存的是富文本字段转义后的 HTML 字符串。浏览器按普通 SVG 文本渲染这些内容，因此会把 `<p>`、`<br>` 当作可见字符显示。

## 解决方案

在宿主侧规范化 MindMap 缩略图 SVG：

1. 解码 SVG `<text>` 内容里的 XML 实体。
2. 将 MindMap 富文本 HTML 转为纯文本。
3. 再按 SVG 文本规则转义后写回 `<text>` 节点。

## 实验过程

1. 读取真实问题文件 `server/data/files/fdddd582-dc41-48e8-848d-845ca188f26b/thumbnail.svg`。
2. 输出 `before.svg`，确认首个文本为 `&lt;p&gt;vibe coding&lt;/p&gt;`。
3. 对全部 `<text>` 节点做富文本转纯文本处理。
4. 输出 `after.svg` 和 `preview.html`，确认首个文本变为 `vibe coding`，中文节点保留。

## 运行方法

```bash
cd _experiments/p1-7-mindmap-preview-text
bash run.sh
```

## 预期输出

```text
P1-7 PASS
before[0]=&lt;p&gt;vibe coding&lt;/p&gt;
after[0]=vibe coding
```
