# Changelog

本文件面向用户与对外发布。开发细节见 `_docs/log.md`。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)。

## [0.3.0] - 2026-05-20

### Added

- 可滚动主页：概览统计、快捷新建、最近文件右栏列表与左侧预览
- 临时文件：新建默认仅存于本地，最近列表显示「临时」标记
- 侧栏「主页」置于首位；无打开文件时点击「编辑器」弹出新建对话框

### Changed

- 保存：临时文件首次保存时正式创建服务器文件并出现在文件管理中
- 嵌入与历史：仅对已保存的文件可用
- 离开编辑器：已落库文件的本地草稿仍会提示保存；临时文件可直接切换视图

## [0.2.4] - 2026-05-20

### Added

- MindMap 保存状态回传与原生落盘链路
- Embed Token 读取同源校验
- 前端运行日志上报

### Changed

- 素材库支持分组同步与本地镜像回退

## [0.2.3] - 2026-05-20

### Added

- 多编辑器（Excalidraw、MindMap、文本等）与文件管理
- AI 文生图 / 图转代码、TTD 对话
- 本地草稿、冲突提示、历史版本恢复

## [0.2.0] - 2026-05-20

### Added

- Drawing Space Shell 新架构初始发布：文件树、设置、深链与 Embed 只读模式
