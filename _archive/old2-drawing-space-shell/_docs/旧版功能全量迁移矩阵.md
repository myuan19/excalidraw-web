# 旧版功能全量迁移矩阵

状态含义：`已迁移` | `部分迁移` | `待迁移` | `上游限制`

## 用户可见能力（摘要）

| 模块 | 状态 | 说明 |
| --- | --- | --- |
| 应用入口与路由 | 已迁移 | 深链 `?file=`/`#file=`、embed 模式、编辑器层常驻；侧栏「主页」首位、「编辑器」次位 |
| 主页 | 已迁移 | 可滚动大屏：概览 2×2、快捷新建（无弹窗）、分割区、最近右列表 + 左预览 |
| 临时文件 | 已迁移 | 新建仅前端 `local-temp:*`，保存转正后入文件树；最近列表标「临时」；嵌入/历史需先保存 |
| 文件树与文件卡片 | 已迁移 | CRUD、拖放、下载、移动、embed 入口、搜索高亮、移动端树、sync 徽章 |
| 导入与导出 | 已迁移 | adapter 导入、图片→Excalidraw、批量失败回滚、Excalidraw 真实缩略图 |
| 缩略图 | 已迁移 | pipeline、draft 优先、MindMap sanitize、导入 exportToSvg |
| Excalidraw 编辑器 | 部分迁移 | Shell/AI/TTD/D2C/素材库/冲突/深链；CommandPalette 为 Footer 快捷钮 |
| MindMap 编辑器 | 已迁移 | bridge、revision、open-state、prefetch、缩略图规范化 |
| 历史版本 | 已迁移 | 列表/恢复/未保存确认/保存后刷新事件 |
| Embed 分享 | 部分迁移 | 只读页、token、静态资源；部署级 E2E 待手测 |
| AI | 部分迁移 | streaming、D2C、TTD 侧车历史、icon 打标；TTD 弹窗内会话 UI 上游限制 |
| 素材库 | 部分迁移 | 三层同步、分组数据、折叠、AI 打标；库内增强 UI 未 1:1 |
| 设置 | 已迁移 | AI、Embed、主题/语言、素材库管理 |
| 用户页 | 已迁移 | 占位说明 |

## 内部支撑（摘要）

| 能力 | 状态 |
| --- | --- |
| ServerSync / 文档格式 / 同步状态 | 已迁移 |
| Delta / LocalData / LocalSceneCache | 部分迁移（onIncrement 运行时接线，无 StoreDelta 级 undo） |
| 编辑会话 / 离开保护 / 409 冲突 | 已迁移 | 已落库草稿离开仍提示；临时文件切换视图不弹窗 |
| 后端 files / embed / library / AI / logs | 部分迁移（smoke 已增，旧库全量 smoke 未全迁） |
| 自动化测试 | 部分迁移（39 tests，旧版全集未回迁） |

完整基线验证命令与手测清单见本文档历史版本及 `_docs/新架构全量迁移待办总览.md`。
