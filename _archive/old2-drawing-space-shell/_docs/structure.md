# 文档结构说明

本文件定义 `_docs/` 文档库的组织方式和自定义字段约定。

## 自定义字段

### version

用于追踪文档所描述内容的版本号，格式为语义化版本：`vX.Y.Z`。

```yaml
version: v0.2.0
```

- 当文档描述的产品设计、架构方案、API 规格等存在版本迭代时，**必须**添加 `version` 字段
- 纯知识笔记、调研报告等无版本概念的文档不需要此字段
- 版本号跟随所描述内容的版本，而非文档自身的编辑次数
- 版本变更时同步更新 `updated` 字段，并在文档内的版本记录表中追加新行

### 版本记录表

带 `version` 字段的文档应在正文末尾维护一个版本记录表：

```markdown
## 版本记录

| 版本 | 日期 | 说明 |
|------|------|------|
| v0.1.0 | 2026-05-15 | 初始草案 |
| v0.2.0 | 2026-05-20 | 新架构初始设计 |
```

## 搜索约定

按版本查找文档时使用：

```bash
wiki.sh search --root _docs --query "v0.2.0" --search-fields version
```

按版本 + 标题组合查找：

```bash
wiki.sh search --root _docs --query "架构" --search-fields title,version
```

## 目录策略

- 文档数量少时平铺在 `_docs/` 根目录
- 文档增多后可按主题建子目录
- `raw/` 存放原始材料
